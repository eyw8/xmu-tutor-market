# 测试方案

## 单元测试

| 目标 | 文件 | 覆盖 |
|---|---|---|
| 匹配算法 | matching/score.util.spec.ts | 五分量的边界（价格超预算衰减、科目匹配、时间重叠、距离、评分中性值） |
| 价格指数 | price-index/calculator.spec.ts | 均值/中位数/min/max、趋势环比、需求变化环比 |

运行：`cd backend && npm test`

## 集成测试

- 注册/登录：手机号重复冲突、密码错误 401、返回合法 JWT
- 主页：非学生角色 403、upsert 幂等
- 需求匹配：按分数降序、无权访问他人需求 404

## 端到端（手工）

1. `docker-compose up` 起全栈
2. 注册学生 → 创建家教主页
3. 注册家长 → 发布需求 → 查看匹配结果
4. 验证价格指数数据（未来接入端点后）

## 关键断言示例

匹配：学生(数学/英语, 80元, 周一18-20, 思明区, 4.5分) × 需求(数学, 预算100, 周一19-21, 思明区) → 总分 99
